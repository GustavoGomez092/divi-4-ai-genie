# Divi 5 module notes

Hand-written gotchas merged into the generated module pages by `generate_docs5.py` (`--notes` this directory).
One file per module, named by the block's short name (`blurb.md` for `divi/blurb`); its Markdown is copied
verbatim under the page's `## Gotchas` heading. Back every claim with evidence (schema5, the conversion map in
`research/divi5-schema`, the fixtures in `tests/fixtures/divi5`, or a `research/divi5/*.md` experiment).
